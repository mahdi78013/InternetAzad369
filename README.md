# اپلیکیشن اختصاصی VPN «اینترنت آزاد ۳۶۹» — اتصال با یک دکمه

این پروژه یک کلاینت اختصاصی و پیشرفته VPN برای سیستم‌عامل اندروید است که بر مبنای موتور قدرتمند و فوق‌سریع **sing-box** (هسته رسمی `libbox`) و زبان **Kotlin** با رابط کاربری مدرن **Jetpack Compose** پیاده‌سازی شده است.

هدف اصلی پروژه، ایجاد تجربه‌ای فوق‌العاده ساده، پایدار و امن برای کاربر با فشردن تنها یک دکمه است؛ بدون نیاز یا امکان هرگونه تنظیم دستی، ویرایش URL یا انتخاب سرور.

---

## ۱. ویژگی‌های کلیدی

- **اتصال با یک دکمه (One-Button UX):**
  - فقط یک دکمه بزرگ در صفحه اصلی: «اتصال» / «قطع اتصال» / «تلاش مجدد».
  - بدون منوهای پیچیده، بدون امکان واردکردن یا ویرایش اشتراک، بدون امکان دستکاری کانفیگ‌ها.
- **ادغام واقعی موتور sing-box (`libbox`):**
  - استفاده از کتابخانه بومی رسمی sing-box برای معماری `arm64-v8a` و سازگاری کامل با لایه شبکه اندروید.
  - پشتیبانی کامل از پروتکل‌های مدرن دورزدن فیلترینگ:
    - **VLESS** (با ویژگی‌های پیشرفته **Reality**، **uTLS Fingerprint** و جریان **XTLS-Vision**)
    - **VMess** (ترافیک امن بر بستر WebSocket و TLS)
    - **Trojan** (با امنیت TLS و شبیه‌سازی وب)
    - **Shadowsocks** (رمزنگاری سریع متقارن)
    - **Hysteria 2** (پروتکل مبتنی بر QUIC/UDP با قابلیت Obfuscation)
- **انتخاب خودکار و هوشمند سرور (Auto Selection / URLTest):**
  - استفاده از گروه انتخاب خودکار بومی موتور sing-box (`type: "urltest"`).
  - تست خودکار تأخیر پینگ بین گره‌ها و انتخاب هوشمند سریع‌ترین و پایدارترین نود به همراه تغییر مسیر خودکار در صورت قطعی (Failover).
- **نمایش نشان واقعی کلید VPN سیستم در نوار وضعیت:**
  - استفاده از سرویس استاندارد `VpnService` سیستم‌عامل اندروید.
  - ایجاد واقعی رابط شبکه TUN با آی‌پی‌های `172.19.0.1/30` و `fdfe:dcba:9876::1/126` و روت کامل `0.0.0.0/0` و `::/0`.
  - سیستم‌عامل اندروید بلافاصله پس از برقراری واقعی تونل، آیکون کلید VPN سیستمی را در نوار وضعیت بالای گوشی نمایش می‌دهد.
- **پردازش دو مرحله‌ای سابسکریپشن مهسا (Mahsa):**
  - آدرس مرجع تنظیمات: `https://raw.githubusercontent.com/hiddify/hiddify-app/refs/heads/main/test.configs/mahsa#Mahsa`
  - استخراج خودکار فراداده‌ها (`#profile-title: Mahsa` و `#profile-update-interval: 24`).
  - پردازش خودکار لینک‌های فرعی همراه با Fallback اضطراری.
  - تشخیص خودکار محتوای Base64 و دیکود ایمن.
  - ذخیره‌سازی آفلاین (Cache): تنظیمات سالم قبلی ذخیره می‌شوند و در صورت قطع شبکه یا اختلال در سابسکریپشن، تنظیم خراب جایگزین تنظیم سالم نمی‌شود.
- **امنیت بالا و رعایت حریم خصوصی:**
  - استفاده انحصاری از HTTPS با اعتبارسنجی کامل گواهینامه‌های TLS.
  - عدم ثبت و چاپ لینک‌های محرمانه و اطلاعات احراز هویت در Logcat.
  - جلوگیری از نشت ترافیک (DNS Leak Protection) از طریق هدایت کلیه درخواست‌های DNS به سرورهای امن.
  - نادیده‌گرفتن بسته خود اپلیکیشن در جدول روتینگ VPN (`addDisallowedApplication`) جهت جلوگیری از ایجاد حلقه ترافیکی.

## ۲. جریان دقیق وضعیت‌های اتصال

رابط کاربری دقیقاً طبق استانداردهای خواسته شده طراحی شده است:

| وضعیت (State) | عنوان وضعیت در UI | متن دکمه اصلی | توضیحات |
| :--- | :--- | :--- | :--- |
| `DISCONNECTED` | **آماده اتصال** | **اتصال** | حالت اولیه پس از باز شدن برنامه؛ هیچ ارتباط خودکاری برقرار نیست |
| `WAITING_FOR_PERMISSION` | **در انتظار تأیید مجوز سیستم** | **در انتظار مجوز...** | پنجره رسمی مجوز اتصال VPN اندروید برای کاربر باز شده است |
| `FETCHING` | **در حال دریافت تنظیمات** | **در حال دریافت...** | دریافت پروفایل و لینک‌های فرعی از شبکه با مدیریت خطا و محدودیت حجم |
| `VALIDATING` | **در حال اعتبارسنجی سرورها** | **اعتبارسنجی...** | پارس لینک‌ها و ساختاربندی JSON متناسب با موتور sing-box |
| `CONNECTING` | **در حال اتصال** | **در حال اتصال...** | ایجاد رابط TUN و راه‌اندازی هسته sing-box |
| `CONNECTED` | **متصل** | **قطع اتصال** | تونل برقرار شده و نشان کلید VPN در نوار وضعیت اندروید نمایان است |
| `DISCONNECTING` | **در حال قطع اتصال** | **در حال قطع...** | بستن سرویس، آزادسازی منابع و حذف نشان کلید سیستم |
| `ERROR` | **اتصال برقرار نشد** | **تلاش مجدد** | نمایش پیام خطای شفاف فارسی به همراه امکان تلاش دوباره |

## ۳. معماری فنی پروژه

پروژه به صورت ماژولار و طبق الگوهای Clean Architecture در پکیج `com.internetazad369.vpn` سازماندهی شده است:

```
app/src/main/java/com/internetazad369/vpn/
├── MainActivity.kt                      # اکتیویتی اصلی و مدیریت لانچرهای مجوز
├── data/
│   ├── model/
│   │   ├── ConnectionState.kt           # وضعیتهای مجزای اتصال (Sealed class)
│   │   ├── ProxyConfig.kt               # مدل استاندارد نودهای پروکسی
│   │   └── ProfileMetadata.kt          # مدل متادیتای پروفایل و آمارهای ترافیک
│   ├── parser/
│   │   ├── UriDecoderUtil.kt            # دیکودر ایمن URL و Base64
│   │   ├── ProtocolParser.kt            # پارسر پروتکلهای VLESS, VMess, Trojan, SS, Hy2
│   │   └── SubscriptionParser.kt        # استخراج متادیتا و تفکیک لینکهای سابسکریپشن
│   └── repository/
│       └── SubscriptionRepository.kt    # ارتباط با شبکه، کش‌گذاری آفلاین، محدودیت حجم و فال‌بک
├── core/
│   └── SingBoxConfigGenerator.kt        # تولید فایل ساختاریافته پیکربندی sing-box با urltest
├── service/
│   ├── AzadVpnService.kt                # سرویس اصلی VpnService متصل به PlatformInterface هسته
│   └── VpnServiceStateHolder.kt         # هولدر واکنشی StateFlow برای اشتراک وضعیت با UI
└── ui/
    ├── screens/
    │   └── MainVpnScreen.kt             # صفحه تک‌دکمه‌ای مدرن با تایمر و سرعت زنده
    ├── theme/
    │   ├── Color.kt                     # پالت رنگی تیره و نئونی مدرن
    │   ├── Type.kt                      # تایپوگرافی
    │   └── Theme.kt                     # تم Material3
    └── viewmodel/
        └── VpnViewModel.kt              # منطق کسب‌وکار، چرخه عمر و تایمر دقیق اتصال
```

## ۴. نحوه ساخت و نصب

### پیش‌نیازها:
- **Android SDK:** Platform API 36 / 34 و Build-Tools 36.0.0
- **JDK:** OpenJDK 17
- **Gradle:** نسخه 9.3.1 (شامل فایل اجرایی `gradlew.bat` در پوشه ریشه)

### دستور اجرای تست‌های خودکار:
```bash
gradlew testDebugUnitTest
```

### دستور ساخت فایل APK:
```bash
gradlew assembleDebug
```
فایل APK خروجی در مسیر زیر ایجاد می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

همچنین یک نسخه کپی‌شده از APK آماده با نام `InternetAzad369.apk` در ریشه پروژه قرار دارد.

## ۵. تست‌های اجراشده و راستی‌آزمایی

کلیه بخش‌های کلیدی با موفقیت مورد آزمایش و اعتبارسنجی خودکار قرار گرفتند:

1. **پارس پروتکل VLESS با قابلیت Reality و جریان Vision:**
   - استخراج صحیح `server`, `port`, `uuid`, `security=reality`, `pbk`, `sid`, `flow=xtls-rprx-vision`.
2. **پارس پروتکل VMess:**
   - دیکود موفقیت‌آمیز Base64 JSON و استخراج آدرس سرور، پورت، UUID، مسیر WebSocket و امنیت TLS.
3. **پارس پروتکل Trojan و Hysteria 2:**
   - تایید صحت پارس اطلاعات احراز هویت، رمز عبور، SNI و پورت.
4. **پارس سابسکریپشن مهسا:**
   - خواندن موفق خطوط متادیتا (`#profile-title`, `#profile-update-interval`) و استخراج آدرس‌های فرعی `mci/sub_*.txt` و `mtn/sub_*.txt`.
5. **اعتبارسنجی تولیدکننده کانفیگ sing-box:**
   - تولید صحیح بلوک `inbounds` با رابط TUN (`172.19.0.1/30`)
   - تولید صحیح گروه انتخاب خودکار `urltest` با تگ `auto` و قراردادن آن به عنوان مقصد نهایی روت (`final: "auto"`).
   - اعتبارسنجی ترافیک اختصاصی DNS و عدم نشت ترافیک.
6. **ساخت موفقیت‌آمیز (Assemble APK):**
   - بیلد کامل Gradle به همراه کتابخانه‌های بومی Go (`libbox.so`) و پکیج‌بندی بدون خطا.
